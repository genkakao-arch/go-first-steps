# Го: первые шаги — Telegram Mini App

Личный MVP: 100 коротких задач по Го на доске 9×9 для абсолютного новичка.
Статическое приложение без backend: Vite + Preact + TypeScript.
Это PWA (ставится на главный экран, работает офлайн) и одновременно Telegram Mini App.
Публикуется на GitHub Pages автоматически при push в `main` (`.github/workflows/pages.yml`: полная проверка `npm run check`, затем деплой).

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | локальный сервер разработки |
| `npm run validate` | валидатор всех 100 задач (структура, легальность, смысл решений, неоднозначность, термины, дубликаты) |
| `npm test` | юнит-тесты (правила Го, чтение, задачи, хранение прогресса) |
| `npm run e2e` | e2e-сценарии в Chrome на 360×640, 390×844, 430×932 |
| `npm run test:slow` | партия KataGo против KataGo до конца на реальной сети (~2 мин) |
| `npm run check` | typecheck + lint + тесты + валидатор + production build |

`npx tsx scripts/pv.ts <id>` — помощник автора: какие ходы достигают цели задачи; `... --pv <ход>` — форсированное продолжение.

## Устройство

- `src/go/board.ts` — правила: соседи, группы, свободы, захват, самоубийство (ko не нужен курсу).
- `src/go/reading.ts` — только для валидатора: чтение захвата/побега (лестницы, сети) и поиск жизни/смерти с алгоритмом Бенсона.
- `src/go/evaluate.ts` — проверка хода в приложении: правильность берётся только из заранее заданных ответов задачи; текст «Попробуй ещё» для прочих ходов вычисляется из реальной позиции.
- `src/data/problems/*.ts` — задачи; `src/data/topics.ts` — темы и вводные тексты с новыми терминами.
- `src/progress.ts` — прогресс в `localStorage`, копия в Telegram CloudStorage (в Telegram); повреждённые данные санитизируются.

## Партия с KataGo

Полная партия 9×9 (китайские правила, коми 7, ко). Тренер (`src/play/coach.ts`) комментирует только важное:
факты о позиции (атари, захват, спасение, соединение) проверяются нашим движком, потери в очках — оценка KataGo.
Сила KataGo адаптивная (`src/play/levels.ts`): уровень растёт после победы и падает после поражения.
Подсчёт в конце: мёртвые камни по карте владения KataGo, затем подсчёт по площади (`src/play/scoring.ts`).

KataGo работает прямо в браузере, без сервера: TensorFlow.js в Web Worker
(WebGPU → WASM → CPU), сеть `public/models/katago-small.bin.gz` (b6c96, 3,8 МБ), простой PUCT-поиск (`src/katago/search.ts`).
Загрузчик сети и подготовка входов взяты из web-katrain (MIT), см. `src/katago/vendor/README.md`.
